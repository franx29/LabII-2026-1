# LabII-2026-1

Proyecto desarrollado para **Laboratorio II**, enfocado en la construcción de una plataforma web para **Banco Universitario**, contemplando tanto la **web institucional estática** como la **banca en línea**.

---

## Descripción del proyecto

Este sistema corresponde al desarrollo de una solución web para un banco universitario, orientado a ofrecer una experiencia moderna, clara y responsive para la comunidad universitaria.

El proyecto contempla dos componentes principales:

- **Web institucional (estática):** enfocada en presentar la identidad del banco, sus beneficios, objetivos, servicios y medios de contacto.
- **Banca en línea:** orientada a la futura gestión de funcionalidades dinámicas para operaciones financieras dentro de la plataforma.

En la fase actual se trabajó principalmente la base visual e integración de la **landing page institucional**, dejando preparada la estructura del proyecto para seguir ampliando el sistema.

---

## Objetivo general

Desarrollar una aplicación web para Banco Universitario que integre una **web institucional** y una **banca en línea**, utilizando tecnologías modernas de frontend, una estructura por componentes y control de versiones colaborativo.

---

## Tecnologías utilizadas

- **Vue 3**
- **Vite**
- **Bootstrap 5**
- **Bootstrap Icons**
- **CSS personalizado**
- **Vue Router**
- **Git y GitHub**

---

## Componentes principales del sistema

### 1. Web institucional
La web institucional corresponde a la parte estática del proyecto y tiene como objetivo presentar información general del banco, su propuesta de valor y las secciones principales de navegación.

Entre sus secciones se encuentran:

- Header responsive
- Hero / banner principal
- Beneficios
- Objetivos
- Servicios
- Contacto
- Footer responsive

### 2. Banca en línea
La banca en línea corresponde a la parte funcional y dinámica del sistema, pensada para futuras operaciones del usuario dentro del banco.

Aunque en esta etapa no se desarrolló toda la lógica de negocio, el proyecto ya está estructurado para permitir su crecimiento e integración posterior.

---

## Funcionalidades visuales implementadas

- Navegación responsive para desktop y mobile
- Header con navegación por anclas
- Banner principal (hero section)
- Cards interactivas tipo flip en la sección de beneficios
- Estructura por componentes reutilizables
- Integración de secciones institucionales dentro de una misma landing
- Estilo visual consistente con la identidad de Banco Universitario
